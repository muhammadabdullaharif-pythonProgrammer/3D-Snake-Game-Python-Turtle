# 🐍 3D Snake Game using Python Turtle

A classic Snake Game developed using **Python** and the built-in **Turtle Graphics** library.

The project demonstrates Python programming fundamentals through an interactive game with snake movement, food collection, scoring, collision detection, game-over handling, and restart functionality.

---

## 🎮 Game Preview

### 🐍 Gameplay

The player controls the snake and collects the red food to increase the score.

![Snake Game Gameplay](Screenshot%20%2823%29.png)

### 💀 Game Over

When the snake collides with the game boundary or itself, the game displays the final score and highest score.

![Snake Game Over](Screenshot%20%2824%29.png)

---

## ✨ Features

- 🐍 Classic Snake gameplay
- 🎮 Keyboard-controlled movement
- 🍎 Random food generation
- 📈 Real-time score tracking
- 🏆 Highest score tracking
- 💥 Collision detection
- 🚫 Wall collision detection
- 🐍 Snake-body collision detection
- 💀 Game Over screen
- 🔄 Restart game using Space key
- 🎨 Colorful Turtle Graphics interface
- ⚡ Adjustable game speed
- 🖥️ Full game window
- 🏆 New High Score notification

---

## 🛠️ Technologies Used

- **Python 3**
- **Turtle Graphics**
- **Random module**
- **Time module**

No external Python packages are required.
